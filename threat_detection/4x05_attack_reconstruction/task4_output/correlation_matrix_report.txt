----------------------------------------------------------------
 RECOMMENDED CONTRADICTION RESOLUTION PROCESS
----------------------------------------------------------------
For each contradiction:

1. Identify the exact event.
2. Record the timestamp from each source.
3. Normalize timestamps to UTC.
4. Check timezone differences.
5. Check endpoint clock skew.
6. Check whether one source records:
     - event creation
     - connection initiation
     - packet capture
     - evidence collection
7. Prefer the source closest to the actual event.
8. Document the reason for choosing the authoritative timestamp.
9. If unresolved, keep the event as CONFLICTED.
